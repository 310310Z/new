# フロントエンド要件

## 使用技術
- **フレームワーク**: Next.js（Reactベースのフレームワーク）
  - サーバーサイドレンダリング（SSR）や静的サイト生成（SSG）を活用。
- **UIライブラリ**: React
  - コンポーネントベースで再利用可能な設計。
- **CSSフレームワーク**: Tailwind CSS
  - ユーティリティクラスを使った高速なデザイン開発。
- **状態管理**: ReactのContext API（必要に応じて追加）
  - シンプルな状態管理を実現。
- **画像アップロード**: Supabase Storage
  - Supabaseのストレージ機能を活用して画像を保存。

---

## 画面構成

### 1. トップ画面
- **URL**: `/`
- **要素**:
  - アプリ名を大きく表示。
  - 「日記を書く」ボタン → `/create`
  - 「振り返り」ボタン → `/diaries`

### 2. 日記作成画面
- **URL**: `/create`
- **要素**:
  - タイトル入力フィールド。
  - 本文入力エリア（テキストエリア）。
  - 画像アップロードボタン。
  - 「保存」ボタン → データをSupabaseに送信 → `/`

### 3. 日記一覧画面
- **URL**: `/diaries`
- **要素**:
  - 保存された日記の一覧（タイトル、日付、サムネイル画像）。
  - 各日記をクリックすると、詳細画面へ遷移 → `/diaries/:id`

### 4. 日記詳細画面
- **URL**: `/diaries/:id`
- **要素**:
  - タイトル、本文、画像（存在する場合）、保存日時を表示。
  - 「戻る」ボタン → `/diaries`

---

## コンポーネント設計

### 共通コンポーネント
1. **Header**
   - アプリのタイトルとグローバルナビゲーションを表示。
2. **Button**
   - 汎用的なボタンコンポーネント。
   - サイズ（大・中・小）とスタイル（主ボタン、リンクボタン）を切り替え可能。

### 画面別コンポーネント
1. **トップ画面**
   - **MainButtons**: 「日記を書く」「振り返り」ボタンをラップ。
2. **日記作成画面**
   - **DiaryForm**: タイトル、本文、画像アップロードのフォーム。
3. **日記一覧画面**
   - **DiaryCard**: 日記のサムネイル、タイトル、日付を表示するカード。
4. **日記詳細画面**
   - **DiaryDetail**: タイトル、本文、画像、保存日時を表示。

---

## 動作要件
1. **レスポンシブ対応**:  
   - モバイルファーストの設計。画面幅600px以下の場合は1カラム表示に切り替え。
2. **アクセシビリティ**:  
   - キーボード操作可能なUIを実装。
   - alt属性やaria-labelを適切に使用。
3. **スムーズな遷移**:  
   - ページ遷移時にローディングインジケーターを表示。
4. **入力補助**:
   - 入力フィールドでリアルタイムのバリデーションエラー表示。

## スタイル指針
1. **テーマカラー**:
   - メインカラー: 青 (#1E3A8A)  
   - アクセントカラー: 黄色 (#F59E0B)
2. **フォント**:
   - ベース: `Inter`, サンセリフ系フォント。
3. **UIデザイン**:
   - モダンでミニマルなデザインを採用。
   - Tailwind CSSのコンポーネントを活用しつつ、必要に応じてカスタムクラスを定義。
